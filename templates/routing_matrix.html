How to read this

  1. GA4 routes are automatic. The GA4 tag collects utm_* parameters out of the box — no Tealium work needed.
  2. Tealium routes are the strategic layer. The pre-loader extension (see Integrations) writes UTM values into utag_data, which every downstream tag can read. Deploying it once unlocks all proposed routes below it.
  3. utm_id is our composite key. It splits into agency / targeting / segmentation / asset — the four custom dimensions that make Adecco reporting richer than standard UTM.
  4. Changes go through the admins. If a route changes in Tealium iQ, this page must be updated — it is the single source of truth, not the tag manager UI.
