How this works

  1. 1. Destination URL

    Where will visitors land? The "Check destination" button validates HTTPS, GA4 tracking, load speed, and social preview tags before you publish.

  2. 2. Campaign

    Pick an approved campaign name or request a new one. The admin gets an email; you'll get one back when it's approved (or renamed).

  3. 3. Source → Medium

    Pick a traffic source (e.g. linkedin). The medium dropdown filters to GA4-valid combinations (e.g. sponsored, organic). The GA4 pill shows the predicted channel.

  4. 4. Brand + Country → utm_content

    Pick a GBU + country. The utm_content field auto-fills with brandcode_countrycode (e.g. ade_be). Cannot be edited manually.

  5. 5. Advanced (optional)

    Agency, Targeting Type, Segmentation, Asset Type — these concatenate into utm_id for richer reporting. Source+Medium narrows what's allowed.

  6. 6. Generate

    You get: long URL (full UTM), short URL (branded utm.tag-repo.com/s/...), QR code (PNG + SVG), and direct GA4 links. Optional A/B variant mode.

Pro tip: Try the "guided tour" or use Cmd+K (or Ctrl+K on Windows) to jump anywhere in the tool.
