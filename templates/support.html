Support.

Questions about the tool? Want a new campaign approved? Need a country-specific dropdown value added? Here's how to reach the team.

For Adecco Group employees

  • Suggestion banner: open the builder and click "+ Suggest" at the top. Pick whether you want a new source, medium, asset type, agency value, or just describe what's missing in free text. The admin gets an email and approves directly from the inbox.
  • New campaign request: in the builder, click "+ Request new" next to the Campaign dropdown. Submit the name + reason; admins approve (or rename + comment) and you'll get an email confirmation.
  • Direct contact: johannes.schatt@adeccogroup.com for system issues, bug reports, feature requests.
  • For DE specifics: contact the German Marketing Data Team (DMCC)
  • For CH specifics: contact the Swiss country marketing lead

Common issues

"I can't sign in"
If your password isn't working, an admin can reset it via the Users panel. If your username doesn't exist yet, sign up at {{ base }}/signup.
"My campaign is not in the dropdown"
Either it hasn't been approved yet (check the email confirmation), or it doesn't exist. Use "+ Request new" to add it.
"My source-medium combination isn't allowed"
We enforce GA4-compliant pairs. If you need a new pair (e.g. a new platform), use the "+ Suggest" banner with kind "source + medium combination".
"My email approvals aren't arriving"
Check spam. New domains build sender reputation over weeks. The admin can check delivery status in Resend's dashboard.
"Pre-flight URL check says my page is missing GA4"
Either the page genuinely doesn't have GA4 installed (talk to whoever owns the page), or it's served via Tealium server-side and we can't detect it client-side. The pre-flight is a best-effort check.

For the Microsoft Edge Add-ons reviewer

Test account info, walkthrough, and source code audit details are in the submission kit. Direct contact: johannes.schatt@adeccogroup.com
