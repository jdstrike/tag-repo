Next step: connect the GA4 Data API for real metrics

With the Service Account set up, the Performance Dashboard will show real Sessions, Users, Engaged Sessions, and Conversions per campaign across all 5 properties. Walkthrough:

  1. Open Google Cloud Console → Service Accounts. Create a new project if needed (e.g. "tag-utm-builder").
  2. "Create Service Account" → name utm-builder-ga4-reader → "Create and Continue" → skip the role assignment → "Done".
  3. Click the new service account → "Keys" tab → "Add Key" → "Create new key" → "JSON" → downloads a .json file. Keep this safe, it is your auth credential.
  4. Copy the service account email (looks like utm-builder-ga4-reader@PROJECT.iam.gserviceaccount.com).
  5. For each of the 5 GA4 properties:
    • Open GA4 → Admin → Property → "Property Access Management" → "+" button
    • Paste the service account email, role: Viewer, click "Add"
  6. Enable the GA4 Data API: enable it here for your project.
  7. Send me the JSON key file (or the contents pasted in chat). I wire it into the tool and you'll have live Sessions/Users/Conversions per campaign in the Performance Dashboard.

No additional GA4 cost. The Data API free tier handles 50k tokens/day per property — plenty for our query pattern.
