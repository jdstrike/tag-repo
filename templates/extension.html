How to install (Chrome / Edge)

  1. Click Download extension (.zip) above. A file named tag-utm-builder-extension-v1.0.0.zip will land in your Downloads folder.
  2. Unzip the file. You should see a folder utm-extension/ with manifest.json, popup.html, and a few icons.
  3. Open Chrome and go to chrome://extensions/ in the address bar.
  4. Top-right, toggle Developer mode on.
  5. Click Load unpacked and select the unzipped utm-extension/ folder.
  6. The TAG icon appears in your toolbar. Pin it by clicking the puzzle-piece icon and then the pin icon next to "the Adecco Group UTM Builder".
  7. Click the TAG icon on any tab. If you see "Sign in required", click the button and sign in to utm.tag-repo.com in the new tab. Come back, click the TAG icon again, build a link.

For Firefox: same flow but go to about:debugging#/runtime/this-firefox and load manifest.json as a temporary add-on. For Safari, we'd need to build a separate package, sag Bescheid if du das brauchst.
