# Branch network

## Brief

The branch network is Adecco's capillary delivery base, blending modern recruiting tech with human contact across cities and rural towns. It is the trust-and-reach layer that pure-digital marketplaces cannot match.

## Key facts

* 3,800 branches in 62 countries
* Three pillars: capillarity, human-powered, glo-cal approach
* Industry-leading branch headcount vs Randstad (~4,700), ManpowerGroup (~2,300), Allegis (~150)
* Delivers volumes for Flexible Placement, Permanent Recruitment, and TSC direct sourcing
* Note: 01 Value Proposition.md and 04 Delivery Models/Branch Network.md cite 5,000+ branches; the canonical portfolio doc states 3,800 in 62 countries (Adecco brand)
