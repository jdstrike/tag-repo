Bar chart

Categorical comparison. Colour bars sequentially using the unity gradient anchors.

Mock
Q1Q2Q3Q4
import matplotlib.pyplot as plt
from tag_chart_style import apply, finalize, tag_palette
apply()
fig, ax = plt.subplots(figsize=(8, 4.5))
ax.bar(["Q1","Q2","Q3","Q4"], [12, 18, 22, 27], color=tag_palette()[:4])
ax.set_title("Quarterly results")
ax.set_ylabel("Revenue (millions)")
finalize(fig, source="Source: TAG internal data (FY26)")

When to use which colour

Single primary series
Use TAG Turquoise #5CB8B2.
Up to 6 categorical
Use the unity-gradient anchors in order: Turquoise, Blue, Purple, Red, Orange, Yellow.
Sequential (heat / intensity)
Tint Turquoise from 10% to 100%.
Diverging (negative / positive)
Red #E30613 (low) to Green #2EA84F (high), via Grey 100 mid.
Status colours
Reserved for status only: success/warning/error/info. Do not reuse for series.

Layout rules

Title
Sentence case, Primary 500, bold.
Axes
Primary 300 labels, Grey 300 axis lines.
Gridlines
Grey 100, horizontal only by default.
Source line
Bottom-left, Primary 300, 12pt.
Unity bar
Always at the bottom of the figure, never resized in height.
Spines
Top and right hidden by default.
Font
Arial in print/Office, Open Sauce Sans on web.

The recipe

All charts on this page can be reproduced with tag_chart_style.py.

import matplotlib.pyplot as plt
from tag_chart_style import apply, finalize, tag_palette

apply()
fig, ax = plt.subplots(figsize=(8, 4.5))
ax.bar(["Q1","Q2","Q3","Q4"], [12, 18, 22, 27])
ax.set_title("Quarterly results")
ax.set_ylabel("Revenue (millions)")
finalize(fig, source="Source: TAG internal data (FY26)")
fig.savefig("chart.png", dpi=200, bbox_inches="tight")
