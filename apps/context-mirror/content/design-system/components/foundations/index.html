Foundations

Color, typography, spacing, radii, elevation, motion.

The visual language every component is built on.

Color system

Primary 500 for body text, Turquoise as the default accent. The 6-stop unity gradient is the canonical brand expression. Don't recolour; don't add stops.

Typography

Open Sauce Sans for digital. Arial for editable Office files. Sentence case in every headline.

Three shadow levels. Use sparingly. Use elevation to signal interactivity, not to decorate.

Motion

Use 120-180 ms ease-out for hover, 200-300 ms for layout transitions. Avoid bouncy easings on TAG.

Tap / hover
120-180 ms, ease-out
Layout shift
220-280 ms, ease-in-out
Modal / drawer
220 ms ease-out (in), 180 ms ease-in (out)
Spinner
900 ms linear, infinite

Iconography

Material-style line icons, 24×24 default, 1.6-2 px stroke. Mirror specific glyphs into /assets/icons/ as needed; don't ship the whole icon set.

Layout grid

12-column grid with 24 px gutters at desktop, 16 px at tablet, 12 px at mobile. Max content width 1200 px.
