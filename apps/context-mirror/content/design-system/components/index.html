Component library

Mirror of the TAG Design System, locally hosted.

What is in here, where it came from, and how to use it.

What is this

A locally hosted, curated mirror of the patterns documented in the official TAG Design System (Storybook + zeroheight). Use it as the canonical reference inside any TAG-branded artefact: landing pages, Pardot, internal portals, vanilla HTML, plus document and slide layouts that AIs can reproduce.

For React product UI, use the actual @adeccoux/tag-ds v4.9.0 package via the Storybook on dev.tagds.adeccogroup.com. The patterns here are for everything that doesn't ship a React build, plus the document layouts the React library doesn't cover.
