Document Library

Every TAG-branded artefact starts from one of these templates. Pick the one that matches your intent, fetch the file, and replace only the body content. Header and footer come from the template, not from your imagination.

TEMPLATE-FIRST is mandatory. If an AI tool is generating a TAG document for you, it must fetch the template from this library, run a recipe from /assets/recipes/, and produce a finished file. It must not synthesize the layout from a description.

Use a template programmatically

The recipes at /assets/recipes/ open a template, replace placeholders, save under a new name. Header and footer are never touched.

pip install python-docx python-pptx matplotlib

# Generate a memo from the canonical TAG template
python replace_docx.py memo \
 --to "Megan Wickens" \
 --from "" \
 --subject "SparkAI integration plan" \
 --body "First paragraph...||Second paragraph...||Third paragraph..." \
 --out memo-megan.docx

Library API:

from replace_docx import fill_template

fill_template(
 template_url_or_path="https://context.tag-repo.com/assets/templates/tag-memo-template.docx",
 replacements={
 "Dear Mr Other": "Dear Megan,",
 "Yours sincerely": "Best,\n",
 },
 output_path="memo.docx",
)

Charts and data visualization

For any chart that ends up in a TAG document or slide, import tag_chart_style first. The unity gradient bar sits at the bottom of the figure (never the top). Title in Primary 500, gridlines in Grey 100, palette is the 6-stop unity gradient anchors.

import matplotlib.pyplot as plt
from tag_chart_style import apply, finalize, tag_palette

apply()
fig, ax = plt.subplots(figsize=(8, 4.5))
ax.bar(["Q1","Q2","Q3","Q4"], [12, 18, 22, 27])
ax.set_title("Quarterly results")
finalize(fig, source="Source: TAG internal data (FY26)")
fig.savefig("chart.png", dpi=200, bbox_inches="tight")
